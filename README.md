# AdventureWorks Sales Dashboard 📊

## Project Overview

This project is part of my journey as a **beginner Data Analyst**, where I am building practical experience by working with business data.

For this project, I analyzed the **AdventureWorks sales dataset** using **Python (Pandas), SQL, and Power BI**. The goal was to explore sales performance, identify useful business insights, and present the findings through an interactive dashboard.

## Tools Used

* **Python (Pandas)** – Data cleaning and analysis
* **SQL** – Data querying and analysis
* **Power BI** – Data visualization and dashboard creation

## Key Areas Analyzed

* Sales performance
* Revenue and profit
* Product performance
* Customer trends
* Regional performance
* Business KPIs

## Dashboard

The final Power BI dashboard provides an interactive view of the sales data and helps highlight important trends and patterns.

**Data → Cleaning → Analysis → Visualization → Business Insights**
